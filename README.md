# Cart – E-commerce Management Demo

Run: open `index.html` in a browser (no build step, no dependencies).
Publish: push to GitHub, then enable **Settings → Pages → Deploy from branch → main / root**.

## Management workflows

- View sales, order count, catalog size, and low-stock metrics on the dashboard.
- Add and edit products in four categories, attach an optional photo URL, search inventory, and adjust stock.
- Add in-stock products to an order, change quantities, and filter or sort the cart.
- Check out with customer and delivery details. The invoice visitor calculates the order total and inventory is reduced.
- Search orders and advance fulfillment through Processing, Shipped, and Delivered. Cancelling an eligible order returns its stock.
- Review pricing, shipping, invoice, and product reports generated by visitors.

Catalog, cart, and order data persist in the current browser's `localStorage`. This is a single-browser demo, not a shared server database. Payment options are simulated; no payment is collected or processed. Tax, discount, and shipping rates are sample values, and product photos require an internet connection.

| Pattern role | Class |
| --- | --- |
| Element | `Product` → `Book`, `Electronics`, `Clothing`, `Grocery` |
| Visitor | `ProductVisitor` |
| Concrete Visitors | `DiscountVisitor`, `TaxVisitor`, `ShippingVisitor`, `InvoiceVisitor`, `ProductReportVisitor` |
| Object Structure | `ShoppingCart` |
| Client | `js/main.js` |

Each product's `accept(visitor)` calls `visitor.visitBook(this)` (etc.) — double dispatch.
Because JavaScript has no overloading, `visit(Book&)` is named `visitBook(book)`.
Tax and discount rates are simulated demo values.
